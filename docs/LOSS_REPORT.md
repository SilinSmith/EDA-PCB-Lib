## 4. 结论

- 四条轴的剩余空间都**不由管线逻辑决定**，而由「5-13px 小字号字形的分框与识别」决定；
  这条瓶颈的全部绕行方案（换识别器配置、pad 扩张、beam top-k 投票、加点检测）都有实测判负记录
  （§5.312 / §5.318 / §5.350 / §5.351）。
- 因此 CPU-only、不重训的前提下，可赚总量约 **+1~2 分**，集中在 pin 的 `pos_far`（808 颗）
  与 `no_pin` 里同位置异号的那 986 颗。
- 需要更大跃升只能换识别器（≥1000 页分角色标注 + `textrec.eval_real` 过闸门），与「不用 GPU」的
  约束冲突，故本阶段不做。

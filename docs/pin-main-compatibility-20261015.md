- 路径按当前检出位置推导，保留主线资源路径环境变量；配置模块导入不再修改 `sys.path`。独立诊断入口也可从其他目录启动。
- 删除提交入口的局部 `traceback` 导入隐患，验证第一张 OCR 失败后仍能处理并导出第二张。
- 接入主线读取器注册接口，恢复此前已经启用的彩色号码裁片、完整词、号码修复和可选名称 OCR。保持横竖排 IC 读数与原始索引对应。
- 元件库只在识别到型号时参与补全，不再把型号缺失时的 `U1` 等位号当作型号模糊查库。保留主线对已识别型号的补全能力。
- 主线的近距离重复槽合并保留用于无实测证据的候选；有当前可信接点证据时禁止跨行搬移号码。固定输入 `0108` 的两个相邻真引脚曾被该启发式错误合并，最终补丁已恢复其原输出。
- 非 IC 实测坐标优先于图章坐标，不凭图章补出未观测到的对侧引脚。二极管被文字证据修正为 LED 后，保留原先测得的两个接点。
- 保留折线逐段采样、方向检查、悬空/合成脚接网限制、IC 外框检查，以及已确认电源/地接点的引用。接入主线导线颜色判别、文本缺口桥接和工程恢复能力。
- 两处旧模块自检现在明确隔离所测试的开关，避免主线默认开关变化导致与测试目标无关的断言失败；产品默认设置不因此改变。

48 个实际冲突文件已逐项处理。没有用跳过测试来隐藏缺失的引脚绑定能力。

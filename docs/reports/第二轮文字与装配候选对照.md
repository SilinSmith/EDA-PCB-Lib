# 第二轮文字与装配候选对照（2026-10-08）

本次以 `a15fb9f` 为基线，针对公开 40 张引脚 F1 不变的原因做开发对照。原先留出的 20 张已进入本次诊断，因此原 40 张全部视为开发数据。另选的 20 张公开图片在代码冻结并完成完整推理后才评价，不能用下面的开发分数替代新验证结果。

没有修改评测器、GT、模型权重，也没有按 GT 位号或图片编号做推理特判。分数是仓库 `schematic_parser.metrics` 重建口径及 SciPy 匈牙利匹配的结果。

## 装配：哪些方案有效

装配候选使用 a15 的第一阶段和已分配文字缓存，实际执行第三阶段 off 的 build、apply、dedup、最终装配。基线最终 JSON 与原来的 50 份导出逐文档精确相同。这是缓存重装配，不是重新运行图片识别。

| 候选 | 公开 40 均分 / pin F1 | 官方 10 均分 / pin F1 | 决定 |
|---|---|---|---|
| a15 基线 | 23.7290 / .062317 | 52.1928 / .357787 | 固定对照 |
| 缺名字时，号置信 ≥.95 才用号作名字 | 23.8730 / .062299 | 52.1887 / .326320 | 引脚退分，未采用 |
| 放宽 A2、F1 等字母数字引脚号 | 23.6123 / .059093 | 52.1678 / .356787 | 退分，未采用 |
| 两项结合 | 23.7154 / .057614 | 52.1656 / .325397 | 退分，未采用 |
| 重复号：后读号 ≥.9、先读号 <.8，且后读名非空 | 23.8563 / .066497 | 52.4764 / .366120 | 收益较小，未作为最终默认 |
| 重复号：允许按号/名质量替换无名先读数 | 24.0795 / .074450 | 52.7200 / .369250 | 新增错误输出，收紧条件 |
| **重复号：两条名字都非空，按号置信×名置信选择代表** | **24.0795 / .075095** | **52.7668 / .377787** | **纳入完整图片推理验收** |

最终条件恢复公开 4 个正确引脚：0129/U1.2、0077/U12.8、0077/U13.1、0160/U19.5。公开 TP/FP 为 32/169 →36/165；官方 TP/FP 为 37/37 →38/36。实际图片和逐引脚链路证据见 [损失链审计](公开40张box引脚损失链审计.md)。

号置信×名置信只是排序量，两个读数来自同一识别器，不能把乘积当成独立、校准的正确概率。缺置信、非法置信或同分时保留先读数；先读数无名字时也保留原过滤政策，避免扩大输出。只更换被保留的原始索引，不把不同端口连成同一个网络。`STAGE2_BOX_PIN_DUPLICATE_BEST=0` 可恢复原先代表选择。

## 位号归属

附近存在符合原资格门限的带数字读法时，不再让纯字母转换出的猜测位号压过它。例如图上的 U5 被内部引脚标签 UD→U0 抢占。保留其他候选原有排序和唯一性规则，不补猜 U6。

在完整实际第三阶段缓存链中，官方 10 张不变，旧 40 张均分 23.7290 →23.7707，收益来自 0110。其中 30 张有原始 OCR 读数并重跑归属；另外 20 张重放保存候选，最终输出不变。最终核心与前者实验的 assigned/final 逐 JSON 完全相同。既有 .02 门限是候选总评分，不是 OCR 置信度门限，框内低置信数字也可能满足它；此规则不能保证位号语义正确。

另一个规则把 0196 的 U1 从装饰边框归回内部真实 IC，但网络分反而下降，该图 23.4551 →21.5684，旧 40 均分减少 .0472；未纳入默认。正确的局部归属不保证在现有下游网络解析中净提分。

## 文字识别：未采用的方向

在 7 张开发图上真实重跑 OCR，保持 a15 其他阶段和其他角色读数，基线 7/7 最终 JSON 精确复现，均分 33.3064、正确评分引脚 10。使用现有模型；没有调用外部模型或读新验证标签。

| 方向 | 实测结果 | 决定 |
|---|---|---|
| 精确宽度分桶、统一补白画布 | 无新增正确引脚，部分方案退分 | 保留原实现 |
| 不收紧文字墨迹裁片 | 32.4557，丢正确引脚 | 未采用 |
| 无词表 CTC beam | 33.3064 或 33.3036，TP 仍为 10 | 未采用 |
| 短裁片水平拉宽 1.25/1.5/2 倍 | 32.3858 /32.3284 /30.9542 | 未采用 |
| 减少上下留白 .5/1/2 px | 32.7126 /32.7126 /31.9360 | 未采用 |
| 只替换低置信原读数的备用裁片 | 33.3064，零新增正确引脚 | 未采用 |

已核对的 FB、PP 短标签在实际归一化裁片中包含完整字符。有效时步上的 B 概率很低，连续 P 没有 blank 而被 CTC 合并；保留额外尾步也没有恢复字符。这个小规模结果支持继续改善识别模型本身，不能据此断言所有短标签错误都相同，也不能凭常见名称补字。

## 验证边界

新增重复号测试覆盖点/名与原索引一致、不同端口不合网、整数/字符串索引、缺名、无效置信、同分、关闭开关、关闭 partial 和唯一号码。独立兼容检查在 50 份缓存上执行 off/all/mixed/cap × partial × need-name：关闭新开关的 800 次装配全文及 pinindex 与 a15 相等；关闭 partial 的另 400 次也完全相等。

候选实测 JSON 和实验入口保存在工作区 `output/eda-pcb-score2-20261008`：`assembly-policy-ab.json`、`duplicate-policy-ab.json`、`complete-duplicate-policy-ab.json`、`assign-slots-development50-ab.json`、`assemble-compat-review.json`，及 `text-*-ab.json`。它们是开发实验，最终交付以冻结代码的完整图片推理结果为准。

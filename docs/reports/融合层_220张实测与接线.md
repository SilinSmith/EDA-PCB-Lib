## 3. 修掉的两个真 bug

### 3.1 `eda-pcb\cvparts\hypo.py` 的 `Slot.add` 合并后不重排

`hypo.py:110-111` 的 `def best(self) -> Alt | None: return self.alts[0] if self.alts else None` —— **`best()` 就是 `alts[0]`**，而列表靠 `hypo.py:99 self.alts.sort(key=lambda a: -a.score)` 维持降序。
原代码合并同值候选时只做 `a.score = max(a.score, alt.score)` 然后 `return` ⇒ **分数涨了、名次没动**，`best()` 会返回分数**更低**的那个候选。

实测（`work\tools\diag\_shapekeys2.py`，case 0001 的 `comp.c0003.key`）：`U580`(0.825) 先入表排第一，随后 `vlm:enrich` 的 `U1`(1.15) 合并进来把 `U1` 抬到 1.15，但 `alts` 顺序仍是 `[U580, U1, U5890]`、`best()` 报 `U580` —— **正确读法被埋掉**。

修法：合并分支里在 `a.score = max(...)` 之后补 `self.alts.sort(key=lambda a: -a.score)`。

### 3.2 `eda-pcb\fusion\claims.py` 的 `_add_vlm` 把器件型号当位号

分支 (b) 原判据 `if PR.DESIG_RE.match(nm): ... put(cid, "key", nm, "Name")`，而 `eda-pcb\fusion\priors.py:79 DESIG_RE = re.compile(r"^([A-Za-z]{1,3})(\d{1,4})$")` —— **器件型号与位号同形**：`MRF521`(MRF+521)、`MAX232`、`BCM2835`、`STC11`、`XOSC1` 全部命中。

后果（case 0036）：键 `U1` 被换成 `MRF521`，而 `U1` 是全文档**唯一带引脚**的元件 ⇒ 一个错改名同时废掉 component tp 与整条 pin/net 贡献（`0036 −16.663`、`0036-Datasheet −15.163`）。

修法：**只有当前键还是占位符 `pNNN`（`FKEY_RE`）或压根没有键时**才允许 `Name` 顶位号，其余一律走 `partname`：

```python
cur = str(rev.get(cid) or "")
use_as_key = (PR.DESIG_RE.match(nm) is not None
              and (not cur or FKEY_RE.match(cur) is not None))
if use_as_key:
    if nm != cur:
        put(cid, "key", nm, "Name")
elif len(nm) >= 4:
    put(cid, "partname", nm, "Name")
```

⚠ 改后命中 `DESIG_RE` 的 `Name` **也会走 `partname`**（原来被 `elif` 挡掉），这是为了保住 `-vlm-name` 那 +0.541 的增益。

效果：`work\_fusion_out220nl` **27.8939 → 28.4200**（+0.53），逐张从「掉 51 张 / 加 26 张」变成「**掉 19 张（−31.252）/ 加 24 张（+32.728）/ 持平 177 张**」。

## 4. 失败的消融（已回退，记录下来免得再试）

`eda-pcb\fusion\priors.py` 分支 (b) `prior:run_free` 的分数是 `(_f(b.score) if b else 0.5) * 0.95`。
`b.score < 0` 时乘 0.95 是把分数**抬高**（−0.5 → −0.475），看起来会「让连号造的号盖过读数」。线索来自 case 0077：真键 `C33,C75,C80,C81,C85,C86` 被换成 **`C77,C78,C180,C181,C185,C186`**，而后者在 `work\_fusion_vlm\0077.json` 与 `stage1\0077.stage1.json` 里**出现 0 次**（纯先验凭空造的号）。

改成「正分打 95 折 / 非正分再低 0.01 / 统一过 `_cap`」后：**28.4200 → 28.3137（−0.11）**，`0077` 从 −4.51 掉到 −5.36，`netH tp 3383→3356 / fp 4492→4519`。

⇒ **已回退到原式**，源码里留了注释。教训：这条先验是**净帮忙**的 —— 它造的那些「图上没有的号」在 `solve` 的连号竞争里替**别的**槽位守住了位置；单独看某一张会觉得它在捣乱，看 220 张才知道它在兜底。

# 节点活性体检 —— 「图上有、链路里没有」的节点

日期：2026-10（`work\tools\diag\_flags.py` / `_vlmdelta.py` / `_basemean.py` / `stage2_eval.py`）
起因：用户提出「如果这个架构真的有看上去那么厉害，就不会拿分这么低了。肯定是链路中的一些节点根本没有发挥作用，比如说 LLM 介导的重新扫描决策有问题之类的」。
结论：**猜对了，而且比猜的更狠。** 22 个节点里 8 个没有代码，唯一实现的那个 LLM 仲裁节点在 220 张上逐位不动，
唯一真正干活的 LLM 节点（VLM 读位号）**不会做任何决策**。

## 1 硬测量：`stage3`（LLM 仲裁）在 220 张上「逐位相同」

同一批产物、同一把尺子（`work\tools\eval\stage2_eval.py`，`work\_submit_out220r32\runs\`）：

| 目录 | 平均加权分 | component F1 | pin F1 | netH F1 | net_line F1 |
|---|---:|---:|---:|---:|---:|
| `stage2`（无 LLM） | **25.2574** | 0.5364 | 0.0657 | 0.2055 | 0.0332 |

`stage2` 与 `stage3` 的 **tp/fp/fn 每一项都完全相同**（component 5351/4128/4258、pin 125/1123/9231、
netH 3221/4818/19325、net_line 690/14775/32347）⇒ **`stage3` 在这 220 张上一次都没决定过任何东西。**

原因写在 `eda-pcb\stage3\arbitrate.py:62-90` 的 docstring 里（2025-10-04 实测改的）：
`mode="auto"` 在 `STAGE3_AUTO_LLM=0`（默认）下**直接落 `off`**；显式写 `mode="llm"` 的 8 张 A/B
**每一项指标逐位相同、逐 case 改动字段 0 个**，而耗时 `off` ≈0 s vs `llm` **1293.4 s（161.7 s/张）**。
根因是结构性的：`_slot_block`（`eda-pcb\stage1\llm.py:170`）把候选的**置信度/分数**写进提示，
而 `qwen3.5-9b` 是**纯文本模型、看不到图** ⇒ 它必然选「分数最高的候选」，而那正是 `assign.py` 已经选中的那个。

## 3 但 `ev_vlm` 是全链路唯一真正干活的 LLM 节点 —— 而它只读字，不推理

`stage2` → `stage3_vlm` 的增量（同一次运行，220 张）：

失配明细的挪动更能说明问题：`component.text_mismatch` 915 → **575**（读对了），
但 `component.bbox_mismatch` 281 → **420**（**涨了 139**）、`component.type_mismatch` 63 → 122，
`pin.position_mismatch` 121 → 168。

⇒ **VLM 只被当成「第二个读者」，而且它的读法还挤掉了原本正确的框归属。**
本来应该拦住这件事的 `plausible`（全局合理性检查）与 `solve`（约束求解）**都不存在**，
所以没有任何环节能说「这个新读法用的框和原读法的框冲突，选一个」。

## 6 结论

1. **「图看着厉害、分低」的直接原因是图上有 8 个节点没有代码，另有 1 个（`stage3`）在 220 张上逐位不动。**
   拿分的仍然是左侧证据层 + `stage2/assign.py` 的局部贪心。
2. **唯一活着的 LLM 节点（VLM）没有被用在任何「决策」上**——它只是第二个 CRNN，
   而且因为它不参与仲裁，还制造了 139 个新的 `component.bbox_mismatch`。
3. **真正的空白在图上画着、代码里没有的那一列**：把「多来源读法 + 结构约束 + 合理性检查」
   接起来的那台机器（`pool`/`solve`/`plausible`/`conflict`/`llm_judge`/`rescan`）。
   按 220 张的失配明细，最该先接的是 **pin 与 netH**：
   `pin.missing 8604 / pin.name_mismatch 428 / net.gt_count 10745 vs net.pred_count 5138`，
   而 VLM 对这两项的贡献是 **+0.0099 / −0.0013**（等于没有）。

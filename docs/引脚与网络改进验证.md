# 引脚与网络改进及验证（2026-10-08）

本次修复折线采样、补脚接线半径和悬空引脚诊断，并提供两个默认关闭的几何保护开关。官方 10GT 的完整流程对照中，默认配置的四项分数均与修改前一致；同时启用两个保护时均分提高 0.1195，但 case 4 下降，因此暂不默认启用。以下分数来自仓库自建评测器，不是赛方正式评测结果。

## 行为变化

- `stage1/pins.py` 按折线的相邻顶点逐段采样，避免将不存在的首尾直线当成导线。纯点云调用接口保持兼容。
- `stage1/nets.py` 中，标记为补出的引脚采用较严格接线半径时，软挂接 `join_far` 不能绕过该限制。负数或不小于普通半径的 `join_synth` 按已有注释恢复普通半径。
- 没有导线时，全部未接线引脚仍记录在 `pin_join.orphans`，距离为 `null`。
- `STAGE1_PIN_DIRECTION_GUARD=1` 仅筛选导线接触候选：保留接近元件边法线的走线，拒绝沿边笔画；角点先按每条边的方向筛选，再选最近兼容边。类型兜底、补桩和列枚举仍按原流程执行。
- `STAGE1_PIN_ATTACHMENT_GUARD=1` 在现有搜索半径内拒绝穿过元件框内部的挂接桥，并将不同导线分量之间精确等距的选择记为歧义。已有导线分组规则及半径不变。
- 第一阶段输出记录两个开关状态，以及 `blocked`、`ambiguous`、`orphans`、`weak` 列表与计数。最终提交 JSON 的坐标和字段协议保持原样。

两个开关默认均为 `0`。接线保护只约束从引脚到导线的新增挂接，不能修复上游已经发生的导线误合并。

# 最新测评规则代码适配与验证

日期：2026-10-15。基础版本为合并冲突已解决的 `e425ac7`，工作分支 `codex/combined-pin-recognition`。本轮只在本聊天工作树修改，不覆盖另一聊天的IC工作树。

## 已修复

- 默认 `latest` 规则统一元件bbox、IC引脚、导线端点的评分容差为20px；识别内部检测、吸附距离未批量放大。
- 普通元件的引脚名称、编号、位置不进入PinF1。网络比较对普通元件采用元件身份，对IC保留具体pin身份；不会因此将普通元件两端所在的网络短接。
- 电源/地跳过自动key匹配，按类别、原样值、几何做一对一配对。即使自动编号相同，也不能绕过值与位置条件。匹配结果统一用于后续网络比较；未匹配对象使用临时内部别名，防止错误的同名key取得连接分或覆盖已匹配对象。
- 修复装配层电源/地 `value` 普遍丢弃的问题。标准GND按符号含义输出GND；可靠归属OCR的电源文字原样输出，支持 `+5V`、`3V3`、`VDD_1.9V` 等；冲突或缺乏证据时保持未知，不默认猜电压。
- 快速评分、阶段二评分、模块入口、固定清单比较和10GT对照工具默认采用最新规则。`protocol2`、`protocol` 及旧判题机复刻保留作历史对照；快速比较不显示不同规则之间的提升差值。
- 逐项错误报告共用元件匹配、IC筛选和网络归一化逻辑，修复旧报告没有重写元件key、仍逐脚比较普通元件、软F1计数不同步等问题。显示保留软计数的小数，报告明确标识本地重建评分。
- 评分与调试入口从任意目录运行时都使用本工作树，避免导入另一份 `eda-pcb` 代码。

## 验证边界

新旧规则比较使用完全相同的冻结预测，单独保存，不能将规则变化写成识别提升。识别改动另以同一套 `latest` 规则前后比较。

本地评分器依据官方书面更新重建，尚未取得新版官方可执行程序。电源几何配对沿用当前可配置bbox判据；bbox20px与mIoU的确切结合、连接器全部字段判分、缺值容错等仍按要求清单保留待核实，不伪造为官方实现细节。

10GT原标注和模型权重均不修改。IC坐标误差只记录与当前GT的差异；不能仅为得到分数而移动有图面依据的真实接点。10GT中黑白案例保留作兼容性检查，不据此声称最终彩图评测表现。

规则适配完成不表示原有识别全部正确。按当前10GT，新输出仍有11个电源符号未匹配正确值：第2图4个、第4图2个、第5图2个、第8图1个、第9图2个。其中10个值未知，第8图为 `VDD_1.9V` 被识别成 `VDD`；不按GT反填输出。

IC仍有3个名称差异与22个超过20px的坐标差异。坐标项只是与当前GT的差异，尤其第9图整颗U2存在约30px的系统偏差，需依据原图和最新GT复核，不能自动将真实连接点移动到旧标注。所有这些差异在本轮前后保持；不是本次规则适配新增的引脚回退。

# 第五轮：真实红绿端点与引脚编号归属

本轮把有颜色区分的 `box` 芯片引脚定位到原图的红绿交界，并修正编号沿真实引脚行匹配、框外数字重裁剪和同号候选选择。指定 10GT 的彩色图 2–10，110 个 GT 芯片引脚中，“编号、名称、所属侧边、沿边位置”同时正确的项 **37→60**；原有 34 个严格正确项的名称、编号、侧边和所在行退化 **0**。

这是诊断结果，**不代表官方得分提高**。对当前 GT 原坐标进行本地严格评分，10 图平均分 **54.8662→47.7962**，引脚 F1 下降。新结果中有 **54 项**名号及物理行正确，但与当前 GT 坐标相差超过 5px。本轮按用户确认的规则输出真实交界，GT 原文件未修改；坐标冲突单列，不能作为严格正确项计分。仍有 **50 项**未达到上述名号与物理行诊断标准。

## 实现

1. **先有芯片框边，再找红桩。** `stage1/pincolor.py` 在检测框附近找原图的长红色本体边，沿四边法向扫描贴框直引脚。按通道主色差保留暗红和抗锯齿像素，避免仅凭亮度漏掉第 8 张。测点不读取 GT、名称或编号，不按图号特判，也不把引脚固定外推若干像素。
2. **坐标来自实际颜色过渡。** 接线引脚取红末端与绿起端的过渡位置；悬空/NC 引脚取红桩端点。内部 `point_img` 使用原图像素、左上角原点；最终 JSON 仍按项目既有左下角原点换算，未改为归一化坐标。
3. **在列枚举之后、网络建图之前应用。** 四条红框边均确认时，以红桩测点替换旧灰度/格点猜点；部分边可确认时只替换有颜色支持的侧，其他侧保留旧候选。测点、证据、连接状态和候选索引同步；被替换的猜点留在 `pin_color` 诊断账中。颜色检测异常记录错误并保留旧路径。
4. **绿色 × 不等于导线。** 先识别斜臂，避免粗 × 中心短绿横段被当成接线。明确 NC/无延续的 `connected=False` 不挂网络，也不允许远距离补挂恢复。长直绿色为 `True`；绿色很短且可能立即转弯为 `None`，保留既有网络附着判断。
5. **名称与号码各用适当的几何。** 名称继续使用已确认本体边界与朝框内方向；号码使用真实端点所在行，并检查所属侧及沿边对齐，不能借名称锚点挪到其他号码行。重叠同号 OCR 去重；只含 `pin_number` 角色的新读数不能参与名称、型号或位号分配。
6. **重新读取框外数字。** `stage2/color_crops.py` 在可信颜色引脚附近，从已有 OCR 框中剪出实际本体边界外的文字，去掉红绿蓝笔画，按深色字形紧框并加小留白。用同一识别器读取精确裁剪，避免自动外扩再把框内圆圈带入。追加读数保留来源；不改旧读数、不合成数字、不把 `13` 硬截成 `1`。
7. **同号胜者保留自身来源。** 可信颜色点的完整名号可替换无名候选；完整候选间只在证据对齐时比较可信度和 OCR 质量。最终选择保留赢家自己的坐标、原索引和网络，不从另一个点借名字、号码或网络。新号码与选胜规则仅在可信颜色证据下启用，纯黑图保留旧行为。

## 几何核对与仍存在的问题

110 个红桩测点中，100 个长绿直线确认接线，7 个明确 NC × 不接网，3 个立即拐弯保持连接状态待定。独立审核另用原图 HSV 像素采样，不调用颜色检测实现：109 点自动支持；第 5 张 `c0001/(678,310)` 因审核窗口截掉斜臂需人工复核，查看接触图确为绿色 NC ×。3 个待定点分别位于图 3、7、9，接触图显示紧接 90° 转弯。**这只是几何和连接形态的证据，不是110个完整引脚都识别正确。**

剩余问题包括：图 3 `U1.pin_6/LX` 的真实测点和名称候选已找到，但正确编号 `6` 没读出，最终编号输出仍缺失；图 3 `FB` 仍读为 `F`；图 8 有 `MISO→ISO`、`LED_P→LED` 等 OCR 拼写错误，也有编号错配使正确文字落在错误 `pin_n` 下。50 项逐项列于实测摘要的 `remaining_errors`；54 项坐标冲突另列在 `coordinate_conflicts`，两类不可混为同一种错误。

这些 10GT 已用于开发，不是独立隐藏测试。当前扫描限制包括检测框附近 ±6px 找红框、红色有效笔画至少 4px、最大扫描长度 96px、引脚横截面不超过 7px。混色红框配黑脚、极短/极长/粗引脚、不完整框和新画风尚未验证；在完整红框上替换灰度猜点时，这些未捕获的真实引脚可能被遗漏。未检测到颜色证据的组件保留旧路径。

## 验证与复现

**194 项测试实际通过。** 覆盖四边红绿测点、暗色与抗锯齿、NC × 与短绿延续、候选替换和证据对齐、明确悬空不接网、号码行与角色隔离、重裁剪、重复号码选择及其自身网络、旧缓存与异常回退。图 3/8 的 `run_case` 在固定检测/文字/导线输入下实际接入，分别得到 6/16 个颜色引脚，错误列表为空，网络引脚索引有效。此接入检查也不等于全模型端到端重跑。

两个新增默认开关：

| 开关 | 默认 | 作用 |
|---|---:|---|
| `STAGE1_PIN_COLOR` | `1` | 在第一阶段启用红绿端点测量和候选替换 |
| `STAGE2_COLOR_NUMBER_CROP` | `1` | 在第二阶段有数字 OCR 时追加可信颜色点的框外数字读取 |

设为 `0` 可关闭对应新路径；环境变量应在启动新进程前设置。第二个开关在关闭 OCR 或只运行不含号码的角色时不生效。新名号匹配仍要求实际可信颜色证据。

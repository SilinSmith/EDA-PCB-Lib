## 4. 怎么验证（一条命令）

```powershell
python -X utf8 work\_verify.py                 # 缺省漂移 / 契约 / 基线 / 按产物重算 / 索引
python -X utf8 work\_verify.py --determinism   # 追加：同案 no-vlm 跑两遍比 sha256（+1~3 分钟）
```

六段全绿时打印 `PASS：缺省、契约、基线、重算、索引全部一致`。
**注意**：VLM 开着时抽样本身有 ±0.2/案的抖动（§5.254），任何「分差」都要先过 `--determinism`
再解释。契约检查覆盖 8 个产物目录、18,718 个引脚，非法脚号/悬空引用/空脚名必须为 0。

## 7. 若要继续往上走，只剩这三条（按可行性排序）

1. **换脚点检测方式**（stage1 级）：官方 10 上 127 个「键+名都对」的脚里有 28 个点距 5–20px，
   修好值 **+5.2**（83.64 → 约 88.8）。但四种 GT-blind 几何全负，得换检测手段（如细线骨架 +
   端点分类），不是调参能到的。
2. **换字符读法**（数据/模型级）：位号、脚号、脚名三条都锁在同一堵墙（32.5% 位号没印、
   脚号读成名字）。需要带「型号→引脚表」的库或更强的 VLM，属于换组件不是调管线。
3. **重切网线簇**（几何级）：§5.267 说明并网必负，要拿那部分分必须重新切线段分组；上限约 +0.5。

## 4. 怎么验证（三条命令，都不跑 VLM）

```powershell
python -X utf8 work\_checkup.py wrapA       # 结构体检：C1/C2/C5/C6/C7/C10 必须全 0
python -X utf8 work\_smoke.py                # 6 族 30 案冒烟，必须 30/30 PASS
```

`work\_keyanchor.py <tag>` 一次报三项锤点（总分 / 键命中 / 脚号集合完全相同的元件数），
当前锚点：`nf2` = 36.4616 / 689 / 561（50 案）。

## 6. 已经证否、别再重跑的路

**识别/成键侧**：微调（§5.307/§5.309/§5.312，11 臂全负）、beam top-k（§5.318，GT 串进 top-6 仅 3.3%）、
四角盲扫（1.6% exact）、残墨重检（0 exact）、远处认领（§5.322，精度 18%）、
GT 框自读（§5.323，106 颗 0 exact）、VLM 当标注者（§5.323，无输出 58%、与 CRNN 一致 18%）、
键形成专职通道（§5.311，判中立）。

**结构/几何侧**：叠框合并（+0.008）、浮空脚全挂回（+0.11）、单成员网剪除（−1.70）、
位号按位置编号（5.1%/3.6%/4.3%/7.2%）、IC 脚号按绕体排序（0.0%/3.1%）、
脚点外推/径向缩放/整体平移（全负）、U 号补缺（负）、旧尺旗标复扫（§5.316，6 臂 0 反转）。

## 7. 若要继续往上走，只剩这两条

1. **换识别器（数据/模型级）**：位号 exact 需从 0.6580 往上，唯一路径是 ≥1000 页分角色标注 +
   `textrec.eval_real` 过闸门。注意 §5.323：GT 键与图上印字存在成对互换，标注必须来自图像而非 GT。
2. **换脚点检测（stage1 级）**：官方 10 上「键+名都对」的脚里仍有 28 个点距 5–20px，
   修好约 +5；但四种 GT-blind 几何全负，得换检测手段（细线骨架 + 端点分类）。

除这两条之外，管线本体的可挖项已经量完：检测 97.3% 饱和，网络损失只有 4.1% 与键无关。

## 4. 关键 A/B 表

### 4.1 并网判据：`weld` / `ext` 路线（**证伪**，基线 56.31）

| 臂 | 官方 9 | netH |
|---|---:|---:|
| `WIRE_WELD=24` | 54.33 | 0.4797 |
| `WIRE_WELD=32` | 51.86 | 0.4147 |
| `WIRE_WELD=40` | 51.86 | 0.4147 |
| `WELD=32 + STAGE1_WIRE_INK=0` | 51.86 | **逐位相同** |
| `WIRE_EXT=12` | 56.31 | 逐位相同 |
| `WIRE_EXT=20` | 53.55 | 0.4603 |
| `WIRE_EXT=30` | 50.48 | 0.3785 |
| `EXT=20 + STAGE1_WIRE_EXT_PERP=6` | 53.55 | **逐位相同** |

**机制**：40 个「共线、相对」的长缺口候选**几乎全部坐在元件本体上**
（`c0006(c)` 16.3 px、`c0005/c0002/c0008/c0004(c)` 28.0 px、`c0007(c)` 42.0 px、
`c0013(gnd)` 44.7 px、`c0012(gnd)` 45.1 px、`c0026(r)`/`c0025(r)` 59.0 px），
只有 2 个缺口中间是空的。抬门限 = 短路所有串联元件。
`WIRE_INK` 无效也解释得通：**元件本体也是墨**。

### 4.2 `WIRE_OVER` 平台（基线 55.73）

`6` 55.38 · `8` 55.38 · `10` 55.99 · **`12` 56.31** · **`14` 56.31** · `16` 55.96 ⇒ 取 12。
`WIRE_OVER_CROSS=1` 各臂 55.35~55.38（更差）。
`WIRE_TOL` 在 1.5/2/3 **逐位相同**（规则 5 上线后），且 `GROUP_TOL` 是**死旋钮**。

**「去重」是诚实反例**：去重在**单点**上是对的（6 个候选确实只有 3 块文字），
但在**指标**上净亏 −1.80 —— 重复副本在**多占坑**：同一块文字绑到两根脚上，
一根 `tp` 一根 `fp`，而 `pin_f1` 里丢 `tp` 比多 `fp` 更贵。

### 4.4 描边剔除：角色集合（基线 56.71）

| 臂 | 官方 9 | component | pin | 派生 19 |
|---|---:|---:|---:|---:|
| 不切（`PINNUM_TIGHT=0`） | 56.7090 | 0.9403 | 0.3548 | 35.3940 |
| 只切 `pin_number` | 56.8493 | 0.9403 | 0.3632 | 35.4898 |
| **切 `pin_number,pin_name`** | **57.5417** | **0.9403** | **0.3920** | **35.7504** |
| 切全部 5 个角色 | 55.6317 | **0.9025** | 0.3802 | — |
| 加 `net_label`（3 个角色） | 57.5417 | 0.9403 | 0.3920 | — |

* 关掉开关**逐位复现基线**（分 / comp / pin / netH / netL / p_tp 全等）⇒ 开关干净。

* `net_label` 加了与不加**逐位相同**（这些图里没有网络标签文字）。

## 5. 负结果归档（别再试）

| 路线 | 结论 | 数字 |
|---|---|---|
| **墨迹尺度归一** | 三版全败 | 判墨迹用行投影 0.146 / 长游程门限 designator 0.84→0.36 / 形态学抠线最好 0.378（基线 0.6815） |
| **更根本的障碍** | 归一化要「复刻训练裁剪」得从墨迹高 `g` 反推标注框高 `H`，实测 `g/H` p5..p95 = **0.47..1.36**（中位 0.60），**不是常数** ⇒ 反推不成立 |
| **二次外扩修正** | 证伪 | 去掉 `pad_box` 崩 39% —— `pad_box` 是**承重的**（检测框比训练标注框更紧，它补回被切掉的字形） |
| **`weld`/`ext` 桥接** | 净亏 | −1.98 ~ −5.83（见 4.1） |
| **引脚号候选去重** | 单点对、指标亏 | −1.80（见 4.3） |
| **`STAGE2_PINCOL`** | 不采纳 | −0.63（见 4.3） |
| **`WIRE_TOL` 钝刀** | 此消彼长 | 官方 +0.82 但派生 −0.75；被规则 5 取代后两者都赚 |
| **`_crnneval.py --shrink`** | 工具本身有缺陷 | 它把「裁掉字形」与「多加白底」混在一起，**不能**用来判外扩优劣；要判外扩必须走 `TextEngine.read` 或端到端 `fast.py` |

## 6. 归因尺子（怎么把失分拆成可行动项）

| 尺子 | 脚本 | 它回答什么 |
|---|---|---|
| netH 三层分解 | `tools/diag/_netloss.py` | GT 网成员 → ① 缺键 ②a 有名元件缺脚号 ②b `∅` 缺脚号 ③ 拓扑错 ④ 正确 |
| 网络并排 | `tools/diag/_netside.py` | 一张图的 GT 网 vs 我们的网，定位碎裂点在哪个坐标 |
| 引脚号 | `tools/diag/_numread.py` | 按**框宽分桶**的读数准确率 + 归属错/识别错归因 + `--dump` 错例拼图 |
| 引脚点来源 | `tools/diag/_numprobe.py` | 「字没检出」还是「检出没认领」 |
| 位号可达性 | `tools/diag/_desigring.py` | GT 位号在它周围 R 像素的文字框里到底**有没有** |
| GT 保真度 | `tools/debug/ledger.py`、`tools/debug/report.py` | 把官方打分过程**逐条摊开**；自造 GT 会骗你 |
| 框外文字带 | `tools/diag/_pinband.py` | 某颗 IC 框外的小文字框，按离框边多远分列 |
| 宽框裁片 | `tools/diag/_widebox.py` | 把「框宽 ≥ N」的裁片连同邻域渲染出来，人眼判「框里到底几个字形」 |

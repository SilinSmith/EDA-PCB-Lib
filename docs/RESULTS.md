### 4.6 `--no-vlm` + `FUSION_LLM=1` 口径（LLM 轮专项，基线 50.06 / 29.68）

**为什么单开一个口径**：boxscan ① 在 VLM 开着时基本是 no-op（`_add_vlm` 已把
`comp.<cid>.key` 覆盖到 82/83、12/12、22/22），② 又要求 LLM 轮真跑；所以只有

+2.42（官方 9）/ +1.64（派生 19）**（对照：LLM 关 = 50.06 / 29.68）。

### 4.7 LLM **上下文块**与整表裁决（`FUSION_JUDGE_CTX` / `FUSION_JUDGE_SHEET_MIN`）

**三个附带发现**：
1. **整表裁决的路原来是死的**：入口是 `if mode == "sheet" and SHEET_ON:`，而 `MODE` 默认
